# Product Roadmap (Team Operating System)

## 1) Product Vision
Собрать повторяемую систему поставки ценности, где TPM/Dev/Design/Marketing работают в едином спринт-цикле и синхронно выводят инкременты продукта.

## 2) North Star + Supporting Metrics
- **North Star:** Активные пользователи, завершившие ключевой сценарий за 7 дней.
- **Product:** activation rate, retention D7/D30.
- **Engineering:** lead time, change failure rate.
- **Design:** task success rate, UX debt backlog.
- **Marketing:** CAC, conversion to activation.

## 3) 90-day Direction

### Horizon 1 (0–30 дней) — Stabilize Foundations
- [ ] Настроить единый backlog и критерии приоритизации (RICE/ICE).
- [ ] Ввести weekly cadence: планирование, демо, ретро, отчёт.
- [ ] Зафиксировать DoD и формат handoff между ролями.

### Horizon 2 (31–60 дней) — Ship Core Improvements
- [ ] Выпустить 2–3 продуктовых инкремента по ключевому пользовательскому пути.
- [ ] Снизить время цикла задач (idea → prod) минимум на 20%.
- [ ] Запустить базовую продуктовую аналитику по воронке.

### Horizon 3 (61–90 дней) — Scale Learning Loop
- [ ] Наладить цикл гипотез: discovery → experiment → decision.
- [ ] Подготовить план следующего квартала на основе фактов/метрик.
- [ ] Сформировать библиотеку повторяемых playbooks (релизы, эксперименты, постмортемы).

## 4) Quarterly Milestones
- **M1:** Team OS зафиксирован и используется всеми ролями.
- **M2:** Первый стабильный релизный ритм (не менее 2 релизов/мес).
- **M3:** Метрики демонстрируют измеримый uplift по активации/retention.

## 5) Key Risks & Mitigations
- **Риск:** Размытые приоритеты между функциями.
  - **Митигация:** Единый backlog owner (TPM) + weekly priority freeze.
- **Риск:** Недостаточная спецификация перед разработкой.
  - **Митигация:** Ready-criteria + обязательный design/dev sync.
- **Риск:** Маркетинг не синхронизирован с релизами.
  - **Митигация:** Release calendar + GTM checklist на спринт.

## 6) Ownership
- **TPM:** cadence, приоритеты, риски, статус.
- **Dev:** реализация, качество, релизы, техдолг.
- **Design:** discovery, UX решения, handoff.
- **Marketing:** позиционирование, GTM, каналы, обратная связь рынка.
